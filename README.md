# GameHall
 早期项目演示链接https://www.bilibili.com/video/BV1L3epeeEP8
基于 ​​C++ + ImGui + Select IO模型​​ 实现了一个支持多游戏类型的​​轻量级联网游戏大厅​​，包含用户系统、房间管理、实时对战等功能，其中五子棋支持多人在线匹配与对战。​​
服务端​​：采用 ​​Select 非阻塞 IO + 事件驱动​​ 模型，自研简易​​会话管理与消息路由机制​​，通过 JSON 协议与客户端通信，支持房间创建、加入、游戏状态同步等功能。
客户端​​：使用 ​​ImGui​​ 快速构建 UI，集成图片资源美化界面，通过网络模块接收服务端指令并更新本地游戏状态。
技术亮点​​：利用 ​​多态与设计模式（如单例模式管理全局对象）​​ 提升代码可维护性；通过映射表动态调用处理函数，实现灵活的消息分发机制。
项目收获：深入理解了网络通信、状态同步、多线程安全等游戏后端核心问题
